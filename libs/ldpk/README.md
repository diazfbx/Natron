# LDPK — Lens Distortion Plugin Kit 2.12.0 (headers)

Science-D-Visions' Lens Distortion Plugin Kit, the reference implementation
of 3DEqualizer's lens distortion models, vendored for the **LD_3DE4** node
(`Engine/Dev/Transform/LD3DE4.cpp`). Only the headers are used (the models are
header-only templates); `nuke_ld_3de4_base.h` (Nuke NDK) is left out.

Source: the `ldpk-2.12.0.tar` archive shipped by mayaMatchMoveSolver
(`external/archives/`), identical to the kit distributed by Science-D-Visions.
